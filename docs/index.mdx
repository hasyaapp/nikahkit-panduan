<Info>
**Yang kamu perlukan**

- Komputer Windows atau Mac dengan Google Chrome. Menyunting undangan hanya bisa di Chrome komputer. Pasangan, tamu, dan staff cukup pakai HP.
- Akun Google untuk masuk ke NikahKit.
- Akun Scalev. Satu undangan memakai satu halaman Scalev, dan jumlah halaman aktif tergantung paket Scalev-mu. Lihat [Akun dan paket Scalev](/scalev/akun-scalev).

## Apa itu NikahKit

NikahKit adalah ekstensi Chrome yang menambah tab **NikahKit** di editor halaman Scalev (Landing Page dengan HTML Mode). Dari tab itu kamu memilih template, mengisi data mempelai dan acara, mengatur warna, font, musik, dan foto. NikahKit menulis undangannya langsung ke halaman Scalev milikmu, jadi undangan tayang di bisnis Scalev-mu sendiri.

Selain editor, membership NikahKit juga memberi:

- **Buku Tamu** di Scalev: ucapan, RSVP, dan tautan personal tamu.
- **Dashboard pasangan**: halaman tempat pasangan mengirim undangan, melihat RSVP dan ucapan, dan check-in tamu di hari-H. Masuknya dengan **PIN dashboard**.
- Halaman **Marketing** untuk jualan: Dashboard pasangan dan Landing page dengan form pesanan yang masuk ke **Pesanan masuk**.

## Tanda berhasil

Kamu siap mulai kalau sudah tahu tiga hal ini:

- Kamu akan bekerja di **Chrome komputer**, di editor halaman Scalev.
- Undangan dibuat di **bisnis Scalev milikmu**, lalu diserahkan ke pasangan bersama **PIN dashboard**.
- Langkah berikutnya: [Pilih paket membership](/gabung/pilih-paket).
