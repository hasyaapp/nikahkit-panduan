---
title: Update ekstensi
description: Perbarui NikahKit ke versi terbaru. Klik Update di banner atau Bantuan, ekstrak ZIP, timpa folder lama, klik ikon muat ulang di chrome://extensions, lalu muat ulang editor Scalev.
---

Di halaman ini kamu memperbarui NikahKit ke versi baru tanpa kehilangan login atau undangan. Caranya: unduh ZIP baru, timpa isi folder lama, lalu muat ulang ekstensi.

<Info>
**Yang kamu perlukan**

- NikahKit yang dipasang lewat Load unpacked. Lihat [Pasang ekstensi NikahKit](/gabung/pasang-ekstensi).
- Tahu di mana folder **NikahKit** lama disimpan (misalnya di **Dokumen**). Folder ini yang dulu kamu pilih saat Load unpacked.
- Langganan aktif atau masih dalam masa tenggang. Unduhan update hanya untuk member aktif. Lihat [Pilih paket membership](/gabung/pilih-paket).
</Info>

<Warning>
Jangan klik **Remove** lalu pasang ulang di folder lain. Cukup timpa isi folder lama: login dan undangan tetap aman.
</Warning>

## Langkah

<Image src="/assets/anim/gabung-update.svg" alt="Panel Template NikahKit menampilkan banner kuning bahwa versi baru NikahKit tersedia (nomor versinya tidak ditampilkan di animasi), dengan tombol Update dan Cara update. Update diklik: muncul petunjuk Ekstrak ZIP, timpa isi folder NikahKit, lalu klik ↻ di chrome://extensions. Folder NikahKit yang baru dibuka, semua isinya dipilih dan disalin, lalu ditempel ke folder NikahKit lama di Dokumen dengan pilihan Replace the files in the destination. Di tab Ekstensi, ikon ↻ pada kartu NikahKit diklik. Terakhir editor Scalev dimuat ulang, tab NikahKit diklik, dan banner update hilang." caption="Update NikahKit dari banner sampai versi baru aktif" />

<Steps>
  <Step title="Lihat banner update di panel NikahKit">
    Saat editor dibuka dan ada versi baru, panel menampilkan banner kuning: **NikahKit** [versi baru] **tersedia.** Anda memakai [versi lama].
    Tidak ada banner? Cek manual: klik **Bantuan** di rail kiri bawah. Di bagian atas jendela Bantuan ada **Versi** [nomor] dan tombol **Cek update**. Klik **Cek update**.
  </Step>
  <Step title="Klik Update">
    Chrome mulai mengunduh file ZIP NikahKit (namanya memuat nomor versinya). Di banner muncul petunjuk **Ekstrak ZIP, timpa isi folder NikahKit, lalu klik ↻ di chrome://extensions.**
    Tombol **Cara update** membuka bagian update di halaman Cara pasang NikahKit, kalau kamu ingin membaca petunjuk aslinya.
  </Step>
  <Step title="Ekstrak ZIP baru">
    <Tabs>
      <TabItem label="Windows" value="win">
        Buka folder Unduhan, klik kanan ZIP, pilih **Extract All...**, lalu **Extract**. Buka folder hasilnya. Di dalamnya ada folder **NikahKit** yang baru.
      </TabItem>
      <TabItem label="Mac" value="mac">
        Buka folder Unduhan, klik dua kali ZIP. Folder **NikahKit** yang baru muncul. Kalau sudah ada folder bernama sama di Unduhan, Mac memberi nama lain, misalnya dengan angka di belakang.
      </TabItem>
    </Tabs>
  </Step>
  <Step title="Salin semua isi folder NikahKit yang baru">
    Buka folder **NikahKit** yang baru. Pilih semua isinya (Ctrl+A di Windows, Cmd+A di Mac), lalu salin (Ctrl+C atau Cmd+C).
  </Step>
  <Step title="Tempel ke folder NikahKit lama dan timpa">
    Buka folder **NikahKit** lama (misalnya di **Dokumen**). Tempel (Ctrl+V atau Cmd+V). Saat komputer bertanya soal file dengan nama sama, pilih ganti atau timpa semua file.
    <Tabs>
      <TabItem label="Windows" value="win">
        Pilih **Replace the files in the destination** (atau **Ganti file di tujuan**).
      </TabItem>
      <TabItem label="Mac" value="mac">
        Centang **Apply to All** (atau **Terapkan ke Semua**) bila ada, lalu pilih **Replace** (atau **Ganti**).
      </TabItem>
    </Tabs>
  </Step>
  <Step title="Buka chrome://extensions">
    Ketik `chrome://extensions` di kolom alamat Chrome, lalu Enter.
  </Step>
  <Step title="Klik ↻ di kartu NikahKit">
    Ikon panah melingkar ada di kanan bawah kartu NikahKit, di samping sakelar. Nomor versi di kartu berubah ke versi baru.
  </Step>
  <Step title="Muat ulang editor Scalev">
    Kembali ke tab editor Scalev, tekan F5 (Windows) atau Cmd+R (Mac). Klik tab **NikahKit**.
  </Step>
</Steps>

<Info>
Kalau NikahKit dipasang dari Chrome Web Store, jendela Bantuan menampilkan **Versi Web Store: update otomatis.** Kamu tidak perlu melakukan langkah di atas.
</Info>

## Tanda berhasil

<Success>
- Kartu NikahKit di `chrome://extensions` menampilkan nomor versi baru.
- Banner **NikahKit ... tersedia.** tidak muncul lagi di panel.
- Di **Bantuan**, setelah **Cek update**, tertulis **Sudah versi terbaru.**
</Success>

## Kalau ada masalah

<AccordionGroup>
  <Accordion title="Unduhan baru saja dimulai. Cek folder Unduhan, atau tunggu 30 detik untuk mengulang.">
    Kamu menekan **Update** dua kali dalam 30 detik. Unduhan pertama sudah berjalan. Cek folder Unduhan. Kalau memang perlu mengulang, tunggu 30 detik.
  </Accordion>
  <Accordion title="Sesi habis. Masuk lagi, lalu tekan Update.">
    Sesi masuk sudah berakhir saat editor terbuka. Klik tautan **Masuk lagi** di pesan itu, masuk dengan Google, lalu tekan **Update** lagi.
  </Accordion>
  <Accordion title="Khusus member aktif. Hubungi admin lewat WhatsApp.">
    Langganan sudah habis, jadi unduhan update tidak diberikan. Perpanjang paket dulu (lihat [Pilih paket membership](/gabung/pilih-paket)), atau klik tautan WhatsApp di pesan itu.
  </Accordion>
  <Accordion title="Berkas update belum tersedia. Coba lagi nanti.">
    Versi baru sudah diumumkan tetapi berkasnya belum siap. Coba lagi beberapa saat kemudian.
  </Accordion>
  <Accordion title="Gagal membuat tautan. Coba lagi.">
    Tautan unduhan gagal dibuat, biasanya karena internet. Klik **Update** lagi.
  </Accordion>
  <Accordion title="Gagal memeriksa update.">
    Muncul di **Bantuan** saat server tidak terjangkau. Periksa internet, lalu klik **Cek update** lagi.
  </Accordion>
  <Accordion title="Tab Chrome menampilkan: Tautan tidak berlaku. Buka NikahKit lalu tekan Update lagi.">
    Tautan unduhan hanya berlaku sekitar 10 menit dan hanya untuk akun berlisensi. Kembali ke editor Scalev dan klik **Update** lagi.
  </Accordion>
  <Accordion title="Versi di kartu tidak berubah setelah ↻">
    Isi folder belum tertimpa, atau kamu menempel ke folder yang berbeda. Klik **Details** di kartu NikahKit dan lihat lokasi folder yang dipakai Chrome. Timpa isi folder itu, lalu klik ↻ lagi.
  </Accordion>
  <Accordion title='"Manifest file is missing" setelah update'>
    Kamu menempel folder **NikahKit** di dalam folder NikahKit lama (jadi bertingkat), bukan isinya. Hapus folder bertingkat itu, lalu salin isinya saja ke folder lama.
  </Accordion>
  <Accordion title="Ekstensi dimuat ulang. Tutup dialog ini, lalu buka lagi dari panel.">
    Jendela NikahKit masih terbuka saat kamu klik ↻. Tekan Esc, muat ulang editor, lalu buka lagi.
  </Accordion>
  <Accordion title="Ekstensi tidak tersambung. Muat ulang halaman.">
    Editor Scalev belum dimuat ulang setelah ↻. Tekan F5 atau Cmd+R.
  </Accordion>
</AccordionGroup>
